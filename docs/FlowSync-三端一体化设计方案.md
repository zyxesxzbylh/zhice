# FlowSync 三端一体化设计方案

> 版本：v1.0 | 设计方向：深色主题现代生产力工具 | 日期：2026-07-28
>
> 目标：为 FlowSync 设计 **安卓手机端、平板端、PC 端** 三端一致且各端适配的 UX/UI 方案，保持品牌统一的同时充分发挥各设备形态优势。

---

## 〇、设计总览：三端设计原则

### 0.1 三端体验目标

| 端 | 核心场景 | 设计目标 |
|----|---------|---------|
| **安卓手机** | 通勤、外出、碎片时间 | 快速捕获、关键信息优先、单手操作 |
| **平板** | 阅读、思考、轻办公 | 兼顾浏览与编辑、多任务并行 |
| **PC** | 深度工作、规划、复盘 | 多栏布局、高密度信息、键鼠高效操作 |

### 0.2 三端共同原则

| 原则 | 描述 |
|------|------|
| **品牌统一** | 同一套深色主题、同一套清单色、同一套优先级色 |
| **渐进增强** | 移动端保证核心闭环，PC 端提供完整生产力 |
| **数据一致** | 同一数据源、同一交互语义，仅呈现形式不同 |
| **手势/快捷键映射** | 移动端手势 ↔ PC 快捷键保持语义一致 |
| **响应式断点** | `< 768px` 移动端 / `768-1023px` 平板竖屏 / `1024-1279px` 平板横屏&小PC / `>= 1280px` 标准 PC |

### 0.3 三端布局总览

```
┌─ 安卓手机（< 768px）───────────────────────┐
│  底部 Tab + 主区域（单栏）                  │
│  顶部固定 Header                           │
│  任务详情全屏弹层                           │
└────────────────────────────────────────────┘
┌─ 平板（768-1279px）─────────────────────────┐
│  侧边栏可隐藏 + 主区域（双栏）              │
│  详情右侧抽屉（横屏）                      │
│  任务卡片双列网格（竖屏可选）               │
└────────────────────────────────────────────┘
┌─ PC（>= 1280px）───────────────────────────┐
│  侧边栏 + 主区域 + 详情面板（三栏）         │
│  顶部命令栏 + 全局搜索                      │
│  完整快捷键 + 多选批量操作                  │
└────────────────────────────────────────────┘
```

## 一、安卓手机端（Android Mobile）

### 1.1 设备假设

- 屏幕尺寸：5.5" - 6.7"（360 x 640 dp - 412 x 915 dp）
- 操作系统：Android 12+
- 输入：单手触控为主，辅以 Android 系统返回手势
- 使用场景：通勤地铁、午休、外出、会议间隙

```

|-----|------|-------|------|

| 任务 | 📋 checklist | 强调色 + 加粗 | 今日任务数（红色超过9） |

**FAB 中央凸起设计**（参考 Material Design 3）：
- 中间"+"按钮采用 56dp 圆形 FAB
- 背景强调色（蓝色），白色加号
- 点击弹出快速添加任务浮层
- 上下展开小动画（200ms）

- 卡片间距：8dp
- 圆角：12dp
- 背景：`#252525`
- 高度：默认 64dp（无子任务）/ 展开后 64 + 子任务数 × 32dp

**优先级旗帜：**
- P1 紧急：🚩 红色旗帜

- P3 中：🔵 蓝色旗帜
- P4 低：⚪ 灰色旗帜

### 1.6 智能清单切换器（横向滚动 Pill）

移动端用横向滚动的 Pill 替代侧边栏：

```
┌──────────────────────────────────────────────┐
│  [📊所有 23] [☀️今天 5] [🌙明天 3]  →        │
│  [📅7天 8]  [📥收集箱 2]  [📰摘要]            │

- 高度：48dp
- 可横向滑动，支持左右惯性
- 当前选中项：背景 `#3a3a3a`，文字 600
- 未选中：背景透明，文字 400
- 数字徽章：右侧小字（11sp）

### 1.9 手势交互（移动端核心）

| 手势 | 触发 | 反馈 |
|------|------|------|
| **左滑任务** | 滑出 > 80dp | 显示 [完成 ✓] [删除 🗑️] |
| **右滑任务** | 滑出 > 80dp | 快速设置今天/明天 |
| **下拉刷新** | 主区域顶部下拉 | 重新加载数据 + 触觉反馈 |
| **长按任务** | 长按 500ms | 触发震动 + 进入批量选择模式 |
| **双指捏合** | 列表/看板视图 | 切换列表/看板/日历 |
| **下拉快速添加** | 顶部下拉到底 | 弹出快速添加 |

| 组件 | 安卓 | 平板 | PC |

| 搜索 | 顶部 🔍 | 顶部 🔍 | `Ctrl+K` |
| 切换清单 | 横向 Pill | 侧边栏 | 侧边栏 / `G+I` |
| 批量选择 | 长按 | 长按 | `Shift+点击` |

### 4.4 视觉一致性

**主题与色板完全统一：**
- 深色背景：`#1a1a1a` / `#1e1e1e` / `#252525`
- 清单 8 色调色板：`--list-red` 到 `--list-gray`
- 优先级 4 色：`--priority-urgent/high/medium/low`
- 强调色：沿用 FlowSync `--accent`

**字体大小三端映射：**
| 语义 | 安卓 | 平板 | PC |
|------|------|------|------|

| 辅助文字 | 12sp | 12sp | 12px |
| 微文字 | 11sp | 11sp | 11px |

### 4.5 数据同步一致性

- **同一数据源**：所有端共用 Supabase 数据库
- **实时同步**：基于 WebSocket / Supabase Realtime
- **离线优先**：本地缓存（SQLite / AsyncStorage），网络恢复后自动同步
- **冲突解决**：最后写入优先 + 时间戳

## 五、开发优先级与实现路径

### 5.1 Sprint 分配（基于 PC → 平板 → 安卓 的渐进路径）

```
Sprint 1-2（4周）— PC 端核心
  ├─ PC 端三栏布局重构（侧边栏 + 主区域 + 详情面板）
  ├─ 任务卡片 V2（多列信息）
  ├─ 富文本编辑器（基础版）
  └─ 命令面板（Ctrl+K）

Sprint 3-4（4周）— PC 端增强
  ├─ 多选批量操作
  ├─ 完整快捷键系统
  ├─ 看板 / 日历 / 时间线视图
  └─ 多窗口支持

Sprint 5-6（4周）— 平板端
  ├─ 平板响应式布局（双栏 / 三栏自适应）
  ├─ 详情抽屉（横屏）
  ├─ 双列网格列表
  └─ 分屏 / 多任务支持

Sprint 7-9（6周）— 安卓端
  ├─ React Native 迁移（共享 PC 端组件）
  ├─ 底部 Tab 导航
  ├─ 简化版任务卡片
  ├─ 全屏任务详情
  ├─ 移动端手势（左滑、长按、下拉刷新）
  └─ 通知栏小部件 + 快速捕获
```

### 5.2 技术栈建议

| 端 | 框架 | UI 库 |
|----|------|------|
| PC | Next.js + React | Tailwind CSS + 自研组件 |
| 平板 | Next.js + 响应式 | 复用 PC 组件 + 平板布局 |
| 安卓 | React Native / Flutter | NativeWind / Material Design 3 |

**响应式策略：**
- **第一阶段**：用 CSS 媒体查询 + 容器查询（Tailwind breakpoints）实现 PC + 平板一套代码
- **第二阶段**：安卓端使用 React Native 共享业务逻辑，UI 单独设计
- **数据层**：统一使用 Supabase + Drizzle ORM，三端共享

### 5.3 验收标准

每个 Sprint 交付需满足：
- ✅ 视觉与设计稿一致（像素级误差 < 2dp）
- ✅ 跨端数据同步延迟 < 500ms
- ✅ 关键交互路径 E2E 测试通过
- ✅ 可访问性：色彩对比度 AA 级、键盘导航完整
- ✅ 性能：列表滚动 60fps、命令面板打开 < 100ms
