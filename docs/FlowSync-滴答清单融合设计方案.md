# FlowSync × 滴答清单融合设计方案

> 版本：v1.0 | 设计方向：深色主题现代生产力工具 | 日期：2026-07-23
>
> 目标：将滴答清单（TickTick）的现代生产力设计语言与 FlowSync 的深度工作管理功能融合，打造一套既有高颜值又有强功能的界面方案。

## 三、界面设计方案

### 3.1 侧边栏重设计（Sidebar Redesign）

当前 FlowSync 的侧边栏只有固定导航项（工作台、任务、知识库、职业成长、设置）。融合滴答清单后，侧边栏变为**任务为中心的清单导航 + 全局模块入口**的双层结构。

#### 结构分层

```
┌──────────────────────────┐
│  🏠 工作台                │  ← 全局模块入口（图标 + 文字）
│  📚 知识库                │
│  📈 职业成长              │
├──────────────────────────┤
│  📋 智能清单              │  ← 分组标题
│  ─────────────────────   │
│  📊 所有            23   │  ← 全部任务计数
│  ☀️ 今天             5   │  ← 动态计算
│  🌙 明天             3   │
│  📅 最近7天          8   │
│  📥 收集箱           2   │  ← 未分类任务
│  📰 摘要                │  ← 周回顾入口
├──────────────────────────┤
│  📁 我的清单      [+]   │  ← 分组标题 + 新建按钮
│  ─────────────────────   │
│  🔴 产品迭代          5 │  ← 彩色圆点 + 清单名 + 计数
│  🟠 客户支持          3 │
│  🟢 个人成长          2 │
│  🔵 团队管理          4 │
│  📂 文件夹A ▼         │  ← 可折叠文件夹
│    ├── 🔴 子清单1    2 │
│    └── 🟢 子清单2    1 │
├──────────────────────────┤
│  ✅ 已完成              │
│  🗑️ 垃圾桶              │
└──────────────────────────┘
```

#### 交互细节

- **清单项悬停**：背景色变为 `#323232`，右侧显示「更多 ⋮」按钮
- **清单项选中**：左侧出现 3px 宽强调色竖线指示器，背景色 `#2a2a2a`
- **计数徽章**：未完成数量，数字在右侧，过期任务数字变红
- **新建清单**：点击 `[+]` 弹出清单创建弹窗
- **拖拽排序**：清单支持拖拽调整顺序（同层级内）
- **拖拽归类**：清单可拖入文件夹，任务可拖入清单

### 3.5 收集箱（Inbox）设计

收集箱是滴答清单的核心概念——一个无压力的任务快速捕获区：

- **入口**：侧边栏「📥 收集箱」，快捷键 `Ctrl/Cmd + Shift + A`
- **快速添加**：任何页面按 `A` 键弹出快速添加浮层
- **行为**：未指定清单的任务自动进入收集箱
- **处理流程**：用户定期清理收集箱，将任务分配至具体清单
- **视觉**：收集箱标题旁显示未分类任务数，超过 10 个变橙色提醒

## 四、交互设计规范

### 4.1 快捷键系统

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `A` | 快速添加任务 | 弹出浮层输入框，直接输入任务标题回车即创建 |
| `Ctrl/Cmd + Shift + A` | 添加至收集箱 | 快速捕获不中断当前工作流 |
| `E` | 编辑选中任务 | 打开任务详情 |
| `Space` | 完成/取消完成任务 | 复选框切换 |
| `D` | 设置截止日期 | 弹出日期选择器 |
| `T` | 添加标签 | 弹出标签输入 |
| `P` | 设置优先级 | 弹出优先级选择 |
| `Shift + ↑/↓` | 多选任务 | 批量操作 |
| `Ctrl/Cmd + K` | 全局搜索 | 已有功能保留 |
| `?` | 快捷键帮助 | 展示全部快捷键 |

### 4.2 手势与拖拽

| 操作 | 触发 | 反馈 |
|------|------|------|
| 拖拽任务 | 按住任务卡片左侧手柄拖动 | 半透明跟随，拖至清单区域高亮 |
| 拖拽清单 | 按住清单项拖动 | 同层级内重排序 |
| 拖拽至文件夹 | 清单拖至文件夹名上 | 文件夹展开，清单归入 |
| 左滑任务 | 触摸设备左滑 | 快速完成/删除选项 |
| 长按任务 | 触摸设备长按 | 进入批量选择模式 |

### 4.3 动画规范

| 场景 | 动画 | 时长 | 缓动 |
|------|------|------|------|
| 任务完成 | 复选框打勾 + 任务淡出下移至已完成区 | 300ms | ease-out |
| 弹窗打开 | 从底部/右侧滑入 + 背景遮罩淡入 | 250ms | cubic-bezier(0.4, 0, 0.2, 1) |
| 弹窗关闭 | 反向滑出 + 遮罩淡出 | 200ms | ease-in |
